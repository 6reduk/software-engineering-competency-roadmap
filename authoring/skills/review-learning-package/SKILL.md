# Review one learning package

## Inputs

Read `authoring/workflow/review-protocol.md`,
`authoring/workflow/lifecycle-boundaries.md`, the review mandate and the frozen
package revision. Select the relevant role instruction:

- technical: `authoring/agents/technical-reviewer.md`;
- learning/editorial: `authoring/agents/learning-editorial-reviewer.md`.

## Ownership

Write only the owned review report. Do not edit reviewed materials, coverage,
state or decisions.

## Stop conditions

When the mandate, frozen revision or required source is unavailable, do not
guess. Mark the affected claim `NOT_VERIFIED` and report the missing input.

## Handoff and lifecycle boundary

Return findings with severity, exact artifact/evidence and the smallest useful
recommendation. Include scope, revision, checks, limitations and a verdict
recommendation. A clean report is not orchestrator acceptance.
