# M2.0 — решение оркестратора по G28

## Решение

Рекомендация выбрать B5 сохраняется. Оба независимых профиля подтвердили её
портфельную и структурную состоятельность; ни один профиль не предложил C1, B1,
B7 или другой track как более сильный следующий шаг.

Selection artifact пока остаётся `review`. До acceptance выполняется один
correction-pass по `governance/work-packages/M2.0a-G28-findings-correction.md`.

## Disposition

| Finding | Решение |
|---|---|
| C-1 major | Исправить до acceptance: следующий B5 intake обязан определить наблюдаемый носитель C1-линзы и проверку на close-out без C1 coverage |
| C-2 minor | Исправить до acceptance: привести split B5/B2/B3/B6/B7/C1 к каноническим ownership boundaries |
| C-3 minor | Исправить до acceptance: объяснить три внутренних статуса при первом употреблении |
| C-4 note | Исправить тем же проходом: раскрыть фактический масштаб одной B5-фазы |
| C-5 note | Исправить тем же проходом: явно назвать ролевую последовательность B2 → B3 → B5 и условную связь advanced B7 |
| C-6 note | Исправить тем же проходом: отделить записанное решение/лимит от будущего критерия контраста |
| raw A-2 | Отклонить: D-064 принимает M1.8.21; stale-фраза находится в B2 README и не делает selection неточным |

## Граница

Correction не принимает B5, не создаёт boundary intake, blueprint, Gate 0,
semantic entities, coverage или учебные материалы. Не меняются выбранный track,
четыре кандидата, восемь критериев, максимум двух slices и один следующий пакет.

После handoff авторского correction-pass оркестратор выполняет точечную проверку
C-1–C-6. Только отдельный acceptance-pass может принять B5 как следующую вертикаль
и разрешить подготовку bounded boundary intake.
