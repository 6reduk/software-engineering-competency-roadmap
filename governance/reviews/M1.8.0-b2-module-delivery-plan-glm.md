## Findings

### GLM-A1

```yaml
severity: minor
artifact: curriculum/tracks/b2/module-delivery-plan.md (таблица «Сводка 10 модулей», строка external-service-integration)
criterion: correctness
finding: В колонке «Сценарии» строки external service integration указано «S08, S13», но по scenarios.md S13 принадлежит b2.module.performance-resource-control; у external-service-integration собственный сценарий только S08.
evidence: scenarios.md: строка S13 — module b2.module.performance-resource-control (capabilities: load, cancellation, integrate-external-services). Остальные 9 строк таблицы следуют назначению сценариев по scenarios.md, а строка performance даже помечает чужой S08 квалификатором «slice использует S08». Колонка смешивает ownership и использование без квалификатора только здесь; при том же либеральном правиле http-runtime заслужил бы аннотацию S08, а performance — S02/S13/S15.
impact: Колонка используется для выбора сценария следующего пакета; двусмысленная семантика может навести будущий integration-пакет на чужой pool-saturation сценарий S13, что план сам же запрещает («не ещё один pool-saturation slice»).
recommendation: Указать «S08; S13 затрагивает capability модуля» (по образцу строки performance) либо оставить только S08.
```
