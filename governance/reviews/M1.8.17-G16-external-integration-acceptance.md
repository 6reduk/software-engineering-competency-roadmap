# M1.8.17 — принятие External Integration/S08 slice

## Итог

M1.8.17 и gate G16 приняты с verdict `accepted` как явное однопрофильное исключение:

- профиль A независимо воспроизвёл техническую модель на идентичном baseline и подтвердил Gate 0;
- профиль B временно не выполнялся по решению владельца программы из-за недоступности SaaS-подписки; consolidated review не создавался;
- learning/editorial область прошла ограниченную оркестраторскую risk assessment без заявления второй независимой проверки;
- `0 blocker / 0 major / 0 minor / 4 note` adjudicated без correction package;
- приняты пять artifacts и 9 relationships к трём semantic targets;
- External L1 проверяет применение заданного client contract и исправление одного failure→empty defect;
- External L2 проверяет самостоятельный выбор внутренних исходов, mapping boundary, resource owner и интеграцию фактического outbound HTTP response;
- External L3/L4, A3/B5 proficiency, supporting coverage, production readiness и полное завершение S08 не заявлены.

## Подтверждённое evidence

- `200 application/json` с валидным `offers=[]` сохраняется как `no_offers`.
- Malformed JSON, неверный media type, schema/identity/coercion violations, 5xx, timeout и transport failure не превращаются в предметное отсутствие.
- Независимо воспроизведены 82 входящих проверки, 79 attempts/receipts, `27/27 → 0/27` false absence и recovery `6/6`.
- Реальный HTTPX boundary наблюдает status, media type, bytes/JSON и transport exceptions.
- One-attempt решение проверено на failure rows, а не только на healthy path.
- Timeout отделён от завершения удалённой работы; drain, client close и server cleanup измеряются отдельно.
- Trusted configured target не выдан за SSRF protection; loopback thresholds не выданы за production SLO.

## Принятые ограничения

Авторский stdin probe не сохранён, но профиль A воспроизвёл эквивалентную минимальную модель и удалил временные файлы. Точные timing автора не обязаны совпадать с независимым прогоном; обе серии уложились в заявленные пределы. Release каждого response не инструментировался построчно, а connect-refused не входит в основную матрицу. Эти ограничения явно названы и не меняют bounded External L1/L2 outcome.

## Coverage и граница принятия

Приняты роли `1 reference / 2 explain / 2 probe / 1 practice / 2 assess / 1 integrate`. Принятие относится к одному read-only Pricing operation и правдивому преобразованию внешнего ответа во внутренний исход Quote.

Пакет не повторяет fan-out, deadline propagation, cancellation, pool saturation или S10 testing governance. Он не закрывает автоматически External Service Integration module gate и не начисляет External L3/L4, A3, B5 или Verification coverage.

## Следующий шаг

Обновить B2 module delivery plan по принятому M1.8.17: пересчитать accepted artifacts, relationships, covered/uncovered outcomes, probe-only и состояния десяти модулей, затем выбрать один следующий bounded package.
