## Ответы на обязательные вопросы

1. Stop обоснован как завершение текущего авторского цикла, а не как полнота
   curriculum.
2. Для C1/B7/B6 условия конкретной задачи и value-over-cost не подтверждены;
   phase cap и exit rule заданы; остальные внешние inputs остаются `NOT_VERIFIED`.
3. Границы C1/B7/B6 относительно B2/B3/B5 правдивы и не создают скрытого scope.
4. Learner execution описан достаточно для фазового выбора; конкретный spec и
   среда относятся к следующему use-mode handoff.
5. Долг 12 треков сохраняется без автоматической очереди authoring.
6. Return triggers наблюдаемы и требуют отдельного решения оркестратора.
7. M3.0 можно принять без blueprint, Gate 0, coverage, module gate или запуска
   learner execution.

## Граница следующего шага

После отдельного acceptance разрешён один program authoring close-out/use-mode
handoff. Он не создаёт новую вертикаль или учебный материал. Его задача — закрыть
режим authoring, выбрать один существующий project-spec для первого применения и
зафиксировать revision, среду, первый evidence result и правило отдельной оценки.
