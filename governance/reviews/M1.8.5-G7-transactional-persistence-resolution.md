# M1.8.5 — решение оркестратора по G7

## Решение

Консолидированный verdict `accepted_with_changes` принят: `0 blocker / 0 major / 2 minor / 5 note`. Gate G7 пока не закрыт; требуется один узкий corrections-проход M1.8.5b и orchestrator verification-pass без повторного независимого review.

Оба minor подтверждены:

- A-1 закрывается обязательным конкурентным опытом с двумя разными idempotency keys на одном draft order; одной инспекции схемы недостаточно для заявленного L3 evidence;
- F-1 закрывается человеческим объяснением `claim/lease` при первом употреблении и строкой словаря.

Все notes также включены в M1.8.5b. Они локальны, улучшают техническую однозначность и редакционную связность и не требуют изменения модели компетенций.

## Disposition

| Finding | Решение |
|---|---|
| A-1 | Исправить до acceptance: добавить different-key race и измеримый результат |
| F-1 | Исправить до acceptance: расшифровать `claim/lease` |
| A-2 | Исправить: различить plain unique violation + rollback и `ON CONFLICT` без ложного универсального рецепта |
| A-3 | Исправить: определить поведение запросов на границе retention |
| A-4 | Исправить: квантовать дополнительные kata cases |
| F-2 | Исправить: русские формулировки и локальный термин `replay` |
| F-3 | Исправить: явно сопоставить точки 1–4 с F0–F3 и kata с F2 |

## Ограничения

- semantic IDs, coverage relationships, roles, versions и registrations не меняются;
- новые capabilities/outcomes/scenarios не добавляются;
- G7 не считается пройденным до verification-pass M1.8.5b;
- после успешной проверки отдельный acceptance-проход переводит пять artifacts и регистрации в `accepted`.
