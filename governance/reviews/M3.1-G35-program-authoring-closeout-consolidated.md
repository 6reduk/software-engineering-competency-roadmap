## Ответы на обязательные вопросы

1. Документ закрывает authoring без ложного завершения обучения.
2. Один открытый input правомерен: случайный выбор spec исказил бы реальную задачу.
3. После заполнения трёх полей input достаточен для выбора одного spec, проверки
   среды, первого bounded результата и отдельной оценки.
4. Lifecycle/portfolio claims и owners правдивы.
5. Stop и исключительный характер возврата к authoring сохранены.
6. M3.1 можно принять после C-1; C-2 не блокирует acceptance.
