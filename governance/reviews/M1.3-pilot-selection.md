# M1.3 — review выбора пилотного трека

## Scope

- `governance/planning/M1.3-pilot-selection.md`;
- согласованность с execution plan, метамоделью, skeleton B2, role views, status и decision log.

## Reviewers

- Structure reviewer — формальные критерии, границы этапов, ID/status/process и готовность к M1.4.
- Domain/learning reviewer — репрезентативность B2, ownership, контраст и размер slices, уровни и artifact flow.

Reviewers не редактировали авторский артефакт. Findings сопоставлены и исправлены основным агентом, после чего оба reviewer-а выполнили узкий re-pass.

## Findings и решения

| Severity | Finding | Решение |
|---|---|---|
| Major | `pilot-selection` был несуществующим kind/ID метамодели | Документ оформлен как governance artifact без semantic entity ID |
| Major | У второго slice отсутствовало единое наблюдаемое действие | Добавлены конкретный pool-exhaustion scenario, central action и evidence через tests/telemetry |
| Medium/minor | Диапазон уровней и особенно L5 был заявлен без probe | Добавлен предварительный L1–L4 probe; L5 не создаётся искусственно и проверяется на B2 ownership |
| Medium/minor | Cross-track dependencies не разделяли baseline, reference и ownership | Добавлена boundary table для B1, A3, B3, B7, A2, B6 и C1 |
| Medium/minor | Оба slices могли разрастись за пределы 1–3 briefs | Каждый привязан к одному concrete scenario и минимальному project substrate |
| Minor | Не было быстрой трассировки критериев выбора на B2 | Добавлена таблица `критерий → evidence` без фиктивного числового рейтинга |
| Minor | Не определён момент проверки `index` и `implementation-reference` | Artifact flow распределён по M1.5–M1.6 и самостоятельной реализации |
| Minor | Все failure triggers ошибочно вели к смене пилота | Разделены rework blueprint, recalibration метамодели и условия реальной смены трека |
| Minor | Дата decision log не отражала новые решения | Metadata обновлены |
