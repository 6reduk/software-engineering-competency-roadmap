## B5/broker readiness перед S09

Отдельный prerequisite package или учебный B5 slice не нужен. По принятому прецеденту D-046 readiness становится Gate 0 внутри M1.8.7 и блокирует написание материалов до подтверждения:

1. одного broker/adapter substrate и закреплённых версий;
2. конкретной manual acknowledgement/redelivery модели, включая поведение при падении consumer до ack;
3. bounded retry и одного poison outcome без превращения материала в обзор DLQ;
4. воспроизводимого fault injection `side effect committed → process crash → ack отсутствует`;
5. применимого языка partial failure и redelivery по первичным источникам.

Substrate M1.8.7 фиксируется как RabbitMQ с Python-адаптером `aio-pika`; автор Gate 0 обязан подтвердить актуальные версии и точные semantics по официальным источникам. Если выбранная версия или queue type не позволяют воспроизводимо реализовать bounded retry/poison transition, authoring останавливается и вопрос возвращается оркестратору.
