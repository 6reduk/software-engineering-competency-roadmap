## Ответы на десять обязательных вопросов

1. **Четыре кандидата, восемь критериев, без фиктивного scoring?** Да. Обязательные B5/C1/B1/B7; восемь строк таблицы заполнены предметно; числового рейтинга нет. Screening остальных треков компактен.

2. **Ровно один track и конкретные отсрочки трёх?** Да. Выбран B5. C1/B1/B7 отложены на один фазовый шаг с различимыми причинами и ценой, не списком достоинств.

3. **Baseline B2/B3 совпадает с accepted источниками и не выдаёт coverage за proficiency?** Да. 10/10 flow, 0/10 completion, uncovered/probe-only, D-064; B3 11/2/9, G27/D-071, BR01 не автозапуск. L21 явно разделяет материалы и владение участника. Независимый полный YAML-пересчёт B2 в этот профиль не входил; сверка — с принятыми досье, реестром, close-out, G27 acceptance и D-061–D-071.

4. **Роли и prerequisites канонические?** Да для уровней и hard/conditional списков. Расхождение — широкая формула `service integration — B2` (B-1), не таблица ролей. A1/A3 hard baseline для B5 назван и не выдан за выполненную вертикаль; проверка факта — следующий intake / досрочная остановка.

5. **Первый проход ограничен intake → breadth-pass → 1–2 slices → close-out с проверяемым выходом?** Да. Максимум два slices. Exit: принятый blueprint + первый slice + записанное решение о втором + обязательный close-out. B-3 — прочтение предиката контраста.

6. **Скрытые modules/capabilities/outcomes/scenarios/coverage/Gate 0/конкретные slices?** Нет в артефакте и нет на диске от этого пакета. Будущий путь intake назван и помечен как несозданный.

7. **Один следующий bounded package с одним результатом и non-goals?** Да: B5 boundary intake, один файл, один reviewable результат, non-goals закрывают blueprint/entities/authoring/Gate 0/C1-pass/B2–B3/status.

8. **Ссылки, термины, читаемость?** Ссылки переносимы. Текст читается как decision brief. Первые локальные ярлыки L19–20 — B-2.

9. **Не roadmap всех вертикалей и не полный B5 blueprint?** Не стал. Нет очереди фаз программы и нет карты кластеров B5.

10. **Что до acceptance, что позже?** До acceptance *плана*: B-1. Backlog: B-2. Следующий intake: каноническая граница B5/соседей (уже его результат), A1/A3 concept gap. Authoring: breadth-pass и 1–2 slices после отдельных пакетов. Learner execution / module gates / BR01 / Gate 0 substrate — не M2.0. **Принятие выбора B5 — отдельное решение оркестратора после консолидации профилей; этот отчёт его не заменяет.**
