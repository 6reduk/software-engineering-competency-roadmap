# M1.9.5 — принятие глубокого slice SE01

## Итог

M1.9.5 и gate G26 приняты с verdict `accepted` после двух независимых профилей, консолидации и correction-pass M1.9.5a.

- Исходный verdict `accepted_with_changes` содержал `0 blocker / 1 major / 2 minor / 4 note`.
- C-1 закрыт побайтовым переносом четырёх служебных исходников Gate 0 из основного work package в `governance/work-packages/evidence/m1-9-5-se01-gate0/`.
- C-2 закрыт локальными пояснениями терминов при первом употреблении в пяти автономных материалах.
- C-3 закрыт актуализацией даты B3 README.
- C-4–C-7 приняты с dispositions консолидированного отчёта без содержательного изменения технической модели или coverage.
- Полный G26 и runtime experiment повторно не запускались согласно resolution.

## Verification-pass M1.9.5a

Повторное хеширование подтвердило точное сохранение четырёх evidence-файлов:

| Файл | SHA-256 | Байтовая форма |
|---|---|---|
| `probe.py` | `ed81b839c79f7e014f872991653ef65d2d0524d744f00cfa514bd91ebca3fd2b` | UTF-8 без BOM, LF, один конечный LF |
| `runtime.json` | `256c3cec4001207f30caa96db58c1d128cf1b65768ef9cdb21577359473ee84b` | UTF-8 без BOM, CRLF, без конечного перевода строки |
| `attempt1.json` | `8bd32ee0ff081eba6762502b43f6dcf50b7343ed0acda64153d719694e4f06c8` | UTF-8 без BOM, CRLF, без конечного перевода строки |
| `attempt2.json` | `5cb779babe123101160e5ec92eff26c0943888ea85dbcb1553f8e3696c91b26f` | UTF-8 без BOM, CRLF, без конечного перевода строки |

`probe.py` разбирается Python AST без исполнения; три JSON-файла разбираются как JSON. Основной work package сокращён с 12 591 до 308 строк и с 343 921 до 42 592 байт. Его evidence-index содержит относительные ссылки, claims, hashes, байтовые соглашения, locator, дату, команду и ограничения доказательства; полный probe, JSON-журналы и готовый `CREATE TRIGGER` в нём отсутствуют.

Пять учебных материалов не ссылаются на служебные sidecar-файлы и не получили готового решения. Первые употребления `writer`, `adapter`, `fixtures`, `scaffold`, `guardrails`, `enforcement`, `Control`/`Defect`/`Fixed`, `readback` и `oracle` пояснены локально там, где используются.

Механическая проверка подтвердила YAML, уникальные semantic IDs, ссылки, Python/JSON parsing, Markdown и отсутствие conflict markers/trailing whitespace. Coverage сохранён: 30 отношений к восьми targets, роли `reference 2 / explain 6 / probe 6 / practice 4 / assess 8 / integrate 4`.

## Граница принятия

Acceptance подтверждает техническую и учебную состоятельность SE01 на закреплённом PostgreSQL/psql 18.6 baseline: пять состояний перехода, сосуществование R-old/W-old/R-new/W-new, конкурентный backfill, полный oracle, порядок совместимости/ограничений, lock evidence и stop/resume.

Принятие не подтверждает выполнение kata или project-spec участником, proficiency, production migration, реальный multi-team adoption, ImplementationReference или завершение B3. C-7 консолидированного review сохраняется: L2 `assess` проекта не считается независимым вторым evidence относительно L2 kata.

## Следующий шаг

SE01 завершает второй и последний заранее запланированный глубокий slice B3 после SQ01. Следующий пакет должен быть фазовым B3 consolidation/close-out: зафиксировать достигнутое покрытие, оставшийся долг и критерии возврата к углублению. BR01 автоматически не запускается.
