# Load state

Эта инструкция восстанавливает рабочий контекст из репозитория без истории
диалога, памяти конкретного LLM или локальных заметок автора. Единственный
канонический машинный вход — [current-state.yaml](current-state.yaml).

## Порядок восстановления

1. В чистой Python-среде установить закреплённую зависимость проверки:

   ```powershell
   python -m pip install -r requirements-validation.txt
   ```

2. Из корня репозитория выполнить:

   ```powershell
   python tools/validate_state.py
   ```

3. Прочитать `governance/state/current-state.yaml` и перейти только по
   перечисленным в нём источникам. Не искать «последний шаг» по датам файлов или
   по истории чата.
4. Сверить пять полей результата проверки:
   `program_mode`, `last_accepted_gate`, `module_state`, `debt` и
   `next_action`.
5. Начинать только `publication.next_action`. Любая другая работа требует
   отдельного решения, меняющего манифест.
6. После завершения bounded шага обновить его source-of-truth, принять решение,
   затем атомарно обновить манифест и снова запустить validator.

## Что агент обязан сообщить после загрузки

- текущий режим программы;
- последний принятый gate и acceptance-файл;
- числа состояний модулей;
- группы открытого долга и их triggers;
- ровно одно следующее действие;
- отсутствующие внешние решения, если действие от них зависит.

## Запрещённые выводы

- `accepted`, наличие coverage или `closed-for-authoring` не доказывают, что
  пользователь прошёл материал или подтвердил навык;
- закрытие текущей authoring-фазы не означает разработку всех 15 вертикалей;
- долг и `track-skeleton-only` не образуют автоматическую очередь authoring;
- исторические work packages и reviews не переопределяют более позднее принятое
  решение из манифеста;
- null в `remote_url` или `public_snapshot_tag` нельзя заменять догадкой.

## Идемпотентность

`tools/validate_state.py` работает только на чтение. Два запуска на одном commit
обязаны вернуть одинаковую строку `STATE_OK` и не менять рабочее дерево. Если
проверка не проходит, состояние считается не загруженным: сначала исправляется
расхождение source-of-truth отдельным bounded пакетом.
