# Открытые вопросы

## Решены в M0

1. Принят repository-per-vertical с совместным хранением `learn/interview/katas/project specs`.
2. Приняты треки A1–A3, B1–B11 и C1.
3. Reliability, Observability & Production Engineering принят как отдельная обязательная вертикаль B7.
4. PyTorch принят как основной framework; TensorFlow/Keras — обязательный второй.
5. L5 принят как целевой уровень; L6 — как необязательный ориентир.
6. Принята модель `общий core + 2–4 depth-вертикали + awareness по остальным`.

## Не являются ограничителями программы

- Персональный темп и количество часов в неделю.
- Единый линейный маршрут для всех участников.
- Полноценный курс технического английского.
- Автоматическая проверка заданий.
