# M1.8.5a — исправление PostgreSQL freshness baseline

## Objective

Закрыть единственный intake finding [I-01](../reviews/M1.8.5-orchestrator-intake.md#i-01--major--неверная-текущая-minor-версия-postgresql) до запуска G7. Это механическая коррекция версии, а не переписывание материалов и не новый content package.

## Required context

Полностью прочитать:

1. настоящий work package;
2. `authoring/workflow/content-author-workflow.md`;
3. `governance/reviews/M1.8.5-orchestrator-intake.md`;
4. `governance/work-packages/M1.8.5-transactional-persistence-s07-slice.md`;
5. пять материалов `curriculum/tracks/b2/slices/transactional-orders-operation/`.

## Ownership

Разрешено изменить только:

- `governance/work-packages/M1.8.5-transactional-persistence-s07-slice.md` — только строки B3 readiness record и итог, содержащие PostgreSQL version/freshness;
- `curriculum/tracks/b2/slices/transactional-orders-operation/README.md`;
- `curriculum/tracks/b2/slices/transactional-orders-operation/learn/transaction-boundary-failure-windows.md`;

- `curriculum/tracks/b2/slices/transactional-orders-operation/kata/recover-order-confirmation.md`;
- `curriculum/tracks/b2/slices/transactional-orders-operation/project-spec/resilient-order-confirmation.md`.

Нельзя менять semantic IDs, relationships, coverage, роли, сценарий, версии Psycopg, даты проверки, content status, регистрации и программный status/gate.

## Required changes

1. Заменить закреплённый PostgreSQL baseline `18.4` на `18.6` во всех шести разрешённых файлах, включая YAML `versions` и связный текст.
2. В B3 readiness record исправить утверждение о current stable release: PostgreSQL 18.6 — current minor на 2026-08-21; PostgreSQL 18 остаётся поддерживаемым до 2030-11-14.
3. Сохранить ссылку на официальный [PostgreSQL Versioning Policy](https://www.postgresql.org/support/versioning/) и дату проверки 2026-08-21.
4. Не менять утверждения, не зависящие от minor release: документация `/docs/18/`, `READ COMMITTED`, `fsync=on`, `synchronous_commit=on`, Psycopg 3.3.4 и модель unknown commit.
5. Сохранить итог B3 readiness `confirmed` только после согласованной коррекции всех шести файлов.

## Acceptance criteria

- [ ] `18.4` отсутствует во всех шести файлах Ownership.
- [ ] `18.6` одинаково закреплён в Gate 0, metadata и тексте пяти материалов.
- [ ] Ни один другой version/semantic/coverage field не изменён.
- [ ] Все пять content artifacts остаются в `review`.
- [ ] YAML, относительные ссылки, fences, `<details>`, EOF/newline, conflict markers и trailing whitespace проверены.
- [ ] Handoff перечисляет точные изменённые места и подтверждает отсутствие побочных изменений.

## Handoff

Передать оркестратору:

1. список изменённых файлов и число замен;
2. подтверждение `18.4 → 18.6` по официальному реестру;
3. результаты acceptance checks;
4. открытые вопросы или явное указание, что их нет.
