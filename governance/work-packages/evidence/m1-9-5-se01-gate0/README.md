# Historical Gate 0 evidence — не запускать в общей среде

Файлы этого каталога сохраняют авторское evidence M1.9.5. Они не являются
scaffold, эталонной реализацией или обязательным действием пользователя.

`probe.py` выполняет изменяющие команды внутри Docker-контейнера с именем
`se01-gate0-20260913`, удаляет созданные им database objects и перезаписывает
`runtime.json`. Запускайте его только в отдельном одноразовом контейнере,
созданном для этого опыта, после проверки имени, image digest и команд cleanup.
Не запускайте файл против существующей базы или общего Docker-окружения.

Сохранённые SHA-256 относятся к историческим файлам evidence. Этот README
добавлен позднее как предупреждение и не изменяет их байты или результаты.
