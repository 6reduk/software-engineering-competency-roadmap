# Work packages: исторический scope и handoff

Этот каталог хранит ограниченные задания прошлых authoring/review/correction
проходов: Ownership, разрешённые действия, Gate 0, проверки и handoff.

Work package описывает границы конкретного запуска, а не текущую очередь работ.
Слова `ready`, `review`, «следующий пакет» или старый version baseline внутри
него не переопределяют [`current-state.yaml`](../state/current-state.yaml).
Запуск нового этапа разрешает только актуальный manifest и отдельное решение.

Сохранённые evidence-файлы могут быть исполняемыми и предназначены для аудита,
а не для безусловного запуска. Перед выполнением необходимо прочитать соседнее
предупреждение, проверить изоляцию среды и убедиться, что команда не затронет
существующие ресурсы.
