# A2 Software Engineering Practice

## Mission

Сформировать воспроизводимые практики создания, изменения и сопровождения программного обеспечения индивидуально и в команде.

## In scope

Качество кода, testing/debugging, collaboration, delivery fundamentals, compatibility, документация и engineering feedback loops.

## Non-goals

Языковые механизмы принадлежат B1; конкретные service/API patterns — B2; platform delivery — B6; operational reliability — B7; организационный governance — C1.

## Clusters

- `a2.cluster.source-control-collaboration` — Git, branching, review и совместная работа.
- `a2.cluster.code-design-maintainability` — cohesion, coupling, abstractions и refactoring.
- `a2.cluster.testing-strategy` — test pyramid, contracts, properties и test design.
- `a2.cluster.debugging-root-cause` — evidence-driven debugging и root cause analysis.
- `a2.cluster.profiling-performance` — measurement, profiling и regression control.
- `a2.cluster.dependencies-build-release` — dependency/build/release management.
- `a2.cluster.compatibility-versioning` — API/schema compatibility и versioning principles.
- `a2.cluster.ci-quality-gates` — CI, static analysis и quality gates.
- `a2.cluster.documentation-review` — documentation, code review и knowledge transfer.
