# Ролевые представления

Role view — проекция общей competency matrix на тип инженерной ответственности. Она не создаёт отдельный учебный контент, а задаёт:

- роль каждого трека: `core`, `depth`, `awareness`;
- целевой уровень L1–L5;
- приоритет capabilities и проектов;
- типовые interview expectations.

## Текущие role views

- [Backend / Distributed Systems](backend-distributed-systems.md) — drafting
- [Architecture / Technical Leadership](architecture-technical-leadership.md) — drafting

Оба представления могут использоваться совместно: первое отвечает за техническую глубину в системах, второе — за масштаб решений и влияния.
