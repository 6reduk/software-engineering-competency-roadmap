# Готовые подборки навыков

Подборка — готовый срез общей матрицы компетенций под определённую специализацию
или набор обязанностей. Это не должность, не грейд, не звание и не отдельная
профессия. Один человек может использовать несколько подборок.

Подборка не создаёт отдельные учебные материалы, а указывает:

- значение каждого предметного направления: `core`, `depth`, `awareness`;
- целевой уровень L1–L5;
- приоритетные навыки и проекты;
- типичные ожидания при профессиональной оценке.
