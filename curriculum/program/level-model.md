# Шкала уровней владения навыком

Шкала показывает не объём запомненной информации, а сложность действия, степень
самостоятельности, неопределённость задачи и масштаб последствий. Названия
должностей приведены только как приблизительный ориентир: ожидания компаний
различаются, поэтому основным критерием остаётся наблюдаемое поведение.

| Уровень программы | Условный hiring-тег | Наблюдаемая способность |
|---|---|---|
| L1 — Foundation | Intern / Junior | Объясняет базовые понятия и реализует локальную задачу по ясным требованиям с поддержкой. |
| L2 — Independent | Middle | Самостоятельно реализует типовую функциональность, тестирует и диагностирует распространённые проблемы. |
| L3 — System Owner | Senior | Проектирует и эксплуатирует подсистему, работает с неопределённостью, рисками и нетипичными отказами, помогает другим. |
| L4 — Multi-team | Staff / Lead | Определяет решения и стандарты для нескольких команд, проводит миграции и согласует долгосрочные компромиссы. |
| L5 — Organizational | Principal / Architect | Формирует техническое направление организации, управляет системными рисками и создаёт механизмы устойчивого межкомандного исполнения. |
| L6 — Field-shaping | Expert / Distinguished | Создаёт новые подходы и влияет за пределами организации. Уровень используется как необязательный верхний ориентир, а не обязательный выпускной результат. |

Одна и та же технология может быть освоена на разных уровнях. Знание редкой детали API не повышает уровень само по себе; повышает масштаб и качество самостоятельно принимаемых решений.
